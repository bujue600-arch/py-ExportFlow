## 今天你该看懂的三个点（面试讲解点）

1. **为什么规格先行**：AI 生成代码的问题不是写不出，而是「不可验证、不可回溯」。先把契约（信封/事件/载荷的形状）钉死成文档，AI 的产出就有了机器可校验的对错标准——测试即规格的执行。
2. **信封的设计动机**：前端只需要处理一种成功/错误形状；trace_id 把「用户报障」和「前后端日志」串成一条链路。这是排障契约，不是装饰。
3. **job_version 为什么必须**：网络世界的事件会乱序、重复、丢失。单调版本号 + 「只接受更新」的规则，等价于把乐观锁思想搬进了事件流。
