# D7 练习：亲手跑一遍端到端与断网自愈（今天只有一个练习，但它是全项目的大验收）

> 预计 30 分钟。这是你"验收自己扛得住项目环节"的仪式——亲手把五条 bullet 演给自己看。

## 第 1 步：端到端冒烟（3 分钟）

```powershell
python scripts/e2e_smoke.py
```

预期输出：`E2E SMOKE: PASS ✓`。如果 C 的页面已合并，继续第 2 步；否则用第 2' 步替代。

## 第 2 步：亲手过一遍演示脚本（25 分钟，可录屏）

打开 `docs/demo/demo-script.md`，按演示 A→B→C 亲手走一遍（B 断网自愈是核心：DevTools Offline → 看徽章降级与轮询请求 → Online → 看自动升级）。走完在下面补一段你的时间线记录（复制到你自己的笔记里）：

```
T+0s  创建导出（FILTER 全选）→ 徽章「实时」
T+3s  Offline → 徽章 ?
T+?s  出现轮询请求（间隔 ?s）
T+?s  Online → 徽章 ?，轮询 ?
```

## 第 2' 步（若页面未就绪）：API 层手动演示（等价验证）

```powershell
# 终端1
python -m uvicorn app.main:app --app-dir server
# 终端2：连上 SSE 看事件流
curl.exe -N http://127.0.0.1:8000/api/events
# 终端3：创建任务（另一个 PowerShell）
curl.exe -X POST http://127.0.0.1:8000/api/export-jobs -H "Content-Type: application/json" -H "Idempotency-Key: demo-001" -d "{\"mode\":\"SELECTED_IDS\",\"selected_ids\":[\"a1\"],\"format\":\"csv\"}"
```

观察终端 2 的三连事件（QUEUED→RUNNING→FAILED）与 job_version 1→2→3；再开浏览器 `http://127.0.0.1:8000/docs` 体验幂等：同键重发返回同一任务 id。
