## 练习 1（核心）：亲手实现闭包取消标志（约 15 分钟）

简历原话："useEffect cleanup 中的闭包取消标志保证过期响应不再覆盖新结果"——现在把它变成你亲手写过的代码。

在 `apps/web/src/lib/` 下新建 `cancelFlag.ts`，实现：

```ts
export interface CancelToken {
  cancelled: boolean;
}

export function createCancelToken(): CancelToken;

/** 只有 token 仍是"当前轮"时才应用数据；已被取消/过期则静默丢弃。 */
export function applyIfCurrent<T>(token: CancelToken, value: T, apply: (value: T) => void): void;
```

再新建 `apps/web/src/lib/__tests__/cancelFlag.test.ts`，至少两个用例：

1. `token 未取消 → 数据被应用`（apply 被调用且收到原值）；
2. `token 已被取消 → 数据被丢弃`（apply 不被调用）——模拟 useEffect cleanup 已把 `cancelled` 置 true、慢响应才回来。

提示：第二个用例手工 `token.cancelled = true` 即可，不需要假时钟。

验收：

```powershell
cd apps/web
npx vitest run src/lib
```
