## 练习 1（核心）：给信封加一个 `server_time` 字段（约 15 分钟）

目标：真实需求常这样来——"信封里带上服务器时间"。你要让所有 `/api` 响应变成：

```json
{ "code": 0, "message": "ok", "data": {...}, "trace_id": "...", "server_time": "2026-09-14T20:30:01" }
```

步骤提示：

1. 打开 `server/app/core/envelope.py`，只改 `build_envelope` 函数（保持纯函数：时间在函数内生成没问题）。
2. 时间用 `datetime`：文件顶部 `from datetime import datetime`，取 `datetime.now().isoformat(timespec="seconds")`。
3. **同时**给 `server/tests/test_envelope.py` 的 `test_成功响应_被包装为信封` 加一条断言：`body["server_time"]` 存在且非空——改行为必须连测试一起改，这是本练习真正要教的事。

验收（全部要绿）：

```powershell
pytest server/tests -q
```

## 练习 2（体验）：跑起来，看错误也讲"信封话"（约 10 分钟）

```powershell
# 终端 1（仓库根目录）
python -m uvicorn app.main:app --reload --app-dir server
```

1. 浏览器开 `http://127.0.0.1:8000/healthz` —— 豁免信封的样子；
2. 浏览器开 `http://127.0.0.1:8000/docs` —— FastAPI 自动生成的接口文档（免费午餐）；
3. 浏览器开 `http://127.0.0.1:8000/api/nothing` —— 404 也是信封形状，注意 `code` 是多少；
4. 再开一次并打开开发者工具 Network 面板，看响应头里的 `X-Trace-Id` 和 body 里的 `trace_id` 是否一致；
5. 终端 2 执行，看你**指定**的 trace_id 被透传：

```powershell
curl.exe -H "X-Request-Id: my-trace-001" http://127.0.0.1:8000/api/nothing
```

预期：body 的 `trace_id` 是 `my-trace-001`；同时终端 1 的访问日志行里出现 `[my-trace-001]`——一条链路三种出现位置（响应头/响应体/日志）。

做完把 curl 的输出截图或复制保存（明晚日报里我会问你这题的结论）。
