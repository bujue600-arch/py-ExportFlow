## 练习（核心）：实现「勾选整页 / 取消整页」（约 20 分钟）

场景：真实列表每页 20 行，用户想一键勾选/取消当前页。在 `apps/web/src/features/assets/lib/selection.ts` 末尾实现：

```ts
/** 显式勾选模式下：勾选当前页全部行（已勾的不重复）。 */
export function selectPage(state: SelectionState, pageIds: string[]): SelectionState;

/** 显式勾选模式下：取消当前页全部行。 */
export function clearPage(state: SelectionState, pageIds: string[]): SelectionState;
```

要求：

1. 只在**非全选模式**下生效——若 `state.selectAll === true`，直接原样返回（表头复选框在全选模式下的行为由别的交互承担，别越权）；
2. 不可变更新，不 mutate 传入的 Set；
3. 在 `lib/__tests__/selection.test.ts` 加一个 describe，至少 4 条用例：
   - 空状态勾选整页 → 3 条全选中；
   - 已勾 1 条再勾整页 → 仍 3 条（不重复计数）；
   - 取消整页 → 0 条；
   - 全选模式下调用 → 原样返回（引用相等断言 `toBe(state)`）。

验收：

```powershell
cd apps/web
npx vitest run src/features/assets
```

思考题（明晚日报问）：为什么第 4 条用例断言"引用相等"而不是"内容相等"？提示：React 依赖引用变化触发重渲染。
