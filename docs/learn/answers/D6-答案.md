# D6 练习参考答案（做完再看）

```ts
describe("场景10：降级期间重连成功自动升级（契约 v1.1）", () => {
  it("degraded后5s重连成功_升级connected并停轮询", () => {
    const deps = makeDeps();
    const conn = createSseConnection(deps);
    conn.start();

    for (let i = 0; i < 3; i++) {
      FakeEventSource.instances.at(-1)!.simulateError();
      if (i < 2) vi.advanceTimersByTime(BACKOFF_STEPS_MS[i]);
    }
    expect(deps.onPhaseChange).toHaveBeenCalledWith("degraded");
    expect(deps.pollActive).toHaveBeenCalledTimes(1); // 降级立即一次

    vi.advanceTimersByTime(4_999);
    expect(FakeEventSource.instances.length).toBe(3); // 5s 退避未到，没有新连接
    vi.advanceTimersByTime(1);
    expect(FakeEventSource.instances.length).toBe(4); // 重连未放弃

    FakeEventSource.instances.at(-1)!.simulateOpen();
    expect(deps.onPhaseChange).toHaveBeenCalledWith("connected");

    const calls = (deps.pollActive as ReturnType<typeof vi.fn>).mock.calls.length;
    vi.advanceTimersByTime(30_000);
    expect((deps.pollActive as ReturnType<typeof vi.fn>).mock.calls.length).toBe(calls); // 轮询已停
    conn.stop();
  });
});
```

边界问题的答案：快进 4999ms 时 `instances.length` 应该**仍是 3**——`setTimeout(connect, 5000)` 在 5000ms 整点才触发。测 `-1ms/+1ms` 这组边界是假时钟测试的基本功：**定时器的正确性 = 边界两侧的行为差异**。只测"快进 10 秒后有新连接"是无法区分 5s/10s/立刻重连三种实现的——退避参数的回归就藏在这 1ms 里。

另一个值得注意的实现细节：升级发生在 `onopen`（连接真正建立）而不是"发起重连"，所以不会出现"轮询停了但 SSE 还没连上"的真空期——**先建立新通道再关旧通道**，这是无感切换的通用原则。
