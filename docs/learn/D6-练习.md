# D6 练习：亲手补上「降级期间重连成功自动升级」的测试

> 预计 20 分钟。做完再看 `docs/learn/answers/D6-答案.md`。

## 练习（核心）：给状态机写"场景 10"（约 20 分钟）

今晚的新语义（契约 v1.1）有一条**还没有测试锁定**：降级期间 SSE 重连不放弃，重连成功即自动升级并停止轮询。你来补上它——这就是"模型行为由测试锁定"在增量开发里的日常形态。

在 `apps/web/src/features/jobs/lib/__tests__/sseConnection.test.ts` 里加一个 describe，覆盖完整链路：

1. 三次连续失败 → `degraded`（期间 `pollActive` 被调用：降级立即一次）；
2. 快进 5 秒（第三次失败的退避）→ 应新建第 4 个 FakeEventSource（**重连未放弃**）；
3. 让它 `simulateOpen()` → 相位变 `connected`；
4. 再快进 30 秒 → `pollActive` 调用次数**不再增加**（轮询已停）。

提示：

- 结构照抄"场景5"的失败循环（`for` 三次 error，前两次各快进 1000/2000）；
- 第 4 个实例用 `FakeEventSource.instances.at(-1)`；
- pollActive 次数断言用 `(deps.pollActive as ReturnType<typeof vi.fn>).mock.calls.length` 或 `toHaveBeenCalledTimes`。

验收：

```powershell
cd apps/web
npx vitest run src/features/jobs/lib/__tests__/sseConnection.test.ts
```
