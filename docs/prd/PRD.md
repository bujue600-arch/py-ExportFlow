# PRD：异步导出中心（ExportFlow）

- **版本**：v1.0（2026-09-14）
- **作者**：A（主持）
- **状态**：已评审基线
- **变更记录**：v1.0 初始基线

> 本文档是项目的最高需求规格。实现与契约如与本文冲突，以本文为准；修改本文需团队评审并在变更记录登记。

## 1. 背景与目标

内容创作者在 AIGC 平台生成大量作品（图片 / 视频 / 剧本），需要将作品**导出为文件**用于交付与归档。作品数量大（万级）、导出耗时长（长时任务）、网络不稳定（内网 Wi-Fi），因此导出被设计为**异步任务 + 实时进度推送**的模式。

本项目在教学环境中复现这条链路，验证五个核心能力（对应简历五条 bullet，见 §5 验收标准）。

**Clean-room 声明**：仅依据公开描述重新设计，不含任何公司源码、数据或内部文档。

## 2. 角色

| 角色 | 说明 |
|---|---|
| 创作者 | 唯一业务角色：浏览/筛选作品、跨页选择、发起导出、跟踪进度、下载文件、报障 |

（无管理端、无多租户、无认证——课程范围内明确排除，见 §6。）

## 3. 业务对象

- **作品 Asset**：id、标题、类型（image / video / script）、状态（draft / ready / failed）、标签（多值）、大小（字节）、创建时间。
- **导出任务 ExportJob**：id、状态机（QUEUED → RUNNING → DONE / FAILED）、格式（csv / json）、总数/已处理数/进度、job_version、文件信息、错误信息、幂等键。

## 4. 用户故事（按优先级）

### US1 列表浏览与筛选（对应 bullet 5）
- 作为创作者，我按类型/状态/标签/关键词/时间范围筛选作品并分页浏览。
- 输入筛选条件**不触发请求**；点击「查询」才请求；翻页沿用最近一次提交的筛选条件。
- 快速连续查询时，页面永远展示**最近一次提交**的结果，不出现旧结果覆盖新结果。

### US2 跨页选择与全选（对应 bullet 4）
- 作为创作者，我可以勾选单条、勾选当前页、以及「全选所有筛选结果」（跨页）。
- 全选后可再取消个别条目（排除集）；选择语义在任意筛选组合下**无歧义**。
- 列表规模可达 1 万条，而单次导出上限 **1000 条**：超限时界面给出明确引导而不是静默失败。

### US3 创建导出（对应 bullet 4）
- 作为创作者，我把当前选择导出为 CSV 或 JSON。
- 重复点击/网络重试**不会创建重复任务**（幂等键）。

### US4 实时进度与断线自愈（对应 bullet 1、2）
- 任务创建后，页面通过 SSE 实时刷新进度，无需手动刷新。
- SSE 断连时**自动阶梯重连**（1/2/5/10 秒封顶）；连续失败 3 次自动**降级为轮询**（仅活跃任务，前台 3 秒 / 后台 15 秒）；网络恢复自动升级回 SSE。
- 页面隐藏时主动断连省资源，回前台自动恢复；全程**无需用户刷新页面**。
- 乱序/重复的过期事件不得污染界面状态（job_version 防护）。

### US5 下载与失败处理（对应 bullet 3）
- DONE 的任务可下载文件；下载失败时错误信息**可读**并携带 trace_id。
- 任何报障场景，页面展示 trace_id，凭它可查前后端日志。

## 5. 验收标准（映射五条 bullet）

| # | 验收标准 | 验证方式 |
|---|---|---|
| A1 | 断网→自动降级轮询→网络恢复→自动升级回 SSE，全程页面进度持续更新且无需刷新 | D7 演示脚本 + FakeEventSource 集成测试 |
| A2 | 构造乱序/重复事件，界面状态与最新 job_version 一致；SSE 更新与 HTTP 校准互不冲突 | 集成测试（假时钟）≥ 6 个核心场景 |
| A3 | 所有响应（含下载失败的二进制错误体）解析为同一错误对象形状，含 trace_id；日志可按 trace_id 检索 | 后端 pytest + 前端单测 |
| A4 | 任意筛选组合下三态选择语义无歧义；超 1000 条被拦截并引导；幂等键防重复创建 | 纯函数组件测试 + 后端 pytest |
| A5 | 键入筛选条件不产生请求；快速翻页无错序覆盖 | hook 集成测试 |

## 6. 明确不在范围内（Out of Scope）

- 用户认证/权限、多租户。
- 任务取消、导出模板管理、定时导出。
- 分布式部署、消息队列中间件（队列以 SQLite 命令表 + 进程内 worker 实现，教学优先）。
- 生产级监控（以结构化日志 + trace_id 代替）。

## 7. 非功能约束

- 数据规模：种子数据 1 万条作品，列表与导出全链路可运行。
- 单文件 ≤ 300 行（体量门禁强制，见 `scripts/size_gate.py`）。
- 本地一键启动：后端 `python -m app.main`，前端 `npm run dev`，无外部中间件依赖。
